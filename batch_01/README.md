# 人体跟随、两轴云台、人脸姓名与中文欢迎

从既有云台工程复制出的独立项目。人体负责位置与运动跟踪，人脸负责已登记人员的姓名标记；连续确认后，异步播放“张三，欢迎光临”。超声波和舵机控制仍由原 STM32 固件执行，G1/S1 格式保持一致。

此副本的统一入口是 **`bash run.sh`**。它打开中文控制中心，包含完整模式、人脸预览、姓名登记、语音测试、仅相机、测距监听及三路舵机验证。原项目没有被覆盖，本次没有向香橙派部署或烧录。

## 当前状态与边界

- 保留人体 NPU 推理、单人自动锁定、跨帧关联、中文 UI、实时距离、分析与显示统一旋转 180°。
- 新增 YuNet 人脸检测、SFace 姓名匹配、连续确认、未知/歧义处理，以及本地离线中文欢迎语音。
- 人体默认由 **VIPLite NPU / YOLOv5 `.nb`** 计算；人脸采用 **CPU 低频工作线程，默认最高 2 次/秒**，不是 NPU 人脸识别。
- 彩色采集默认 640×480、请求 30FPS；请求值不等于实际性能。加入人脸和语音后的板端 FPS、身份准确率和音频输出尚未验收。
- 已保留最近验收范围：水平 1100～1900μs、俯仰 1300～1600μs、前轮 1450～1550μs，回中均 1500μs。
- `calibration_confirmed=false`，前轮几何参数尚未填写，**当前默认禁止电机行进**，可做 VM 断开的视觉与云台台架联调。不要仅为启动电机而把这个值改成 true。
- HC-SR04 回波不是带身份的深度测量。随水平云台转向、目标对准、回波新鲜等条件只筛出候选距离，不能证明回波一定来自被锁定的人。

## 在香橙派首次安装

将仓库放到用户可写目录，例如 `~/FaceLock_Gimbal_Face`，然后执行：

```bash
cd ~/FaceLock_Gimbal_Face
bash tools/setup_orangepi.sh
```

脚本安装 Python 环境、中文字体、语音工具、模型和桌面图标，不安装 NPU 内核驱动，也不写 STM32。系统须有 Python 3.10～3.12、桌面环境和可用的中文语音输出设备；NPU 须满足[环境配置](docs/01_安装与环境.md)的实际硬件与 SDK 条件。

## 登记与欢迎

1. 执行 `bash run.sh` 或点击桌面“人脸欢迎与云台控制中心”。
2. 点“测试中文欢迎语音”，确认扬声器能听到声音。
3. 点“登记人脸姓名”，输入姓名，只让该人员一张清楚正脸入镜，采满 8 个样本。
4. 关闭登记窗口，再点“人体＋人脸姓名＋语音预览”。连续确认后显示姓名并欢迎；陌生人显示“未登记”。
5. 预览通过后，VM 断开，选择“完整视觉＋人脸姓名＋语音＋云台＋测距”。

也可以用命令：

```bash
bash run.sh --mode enroll --name '张三'
bash run.sh --mode preview
bash run.sh --mode full
# 明确只跟随某个已登记人脸ID；身份不新鲜/歧义时发无效控制。
bash run.sh --mode full --follow-face 1
```

默认模式按人体规则跟随，并给已知人标姓名/欢迎；不要求每次都看见正脸。`--follow-face` 模式要求身份持续有效，转身较久就会暂停有效转向。两种行为见[姓名与语音说明](docs/03_人脸姓名与语音.md)。
