## 运行平台

主目标为有桌面环境的香橙派 Linux、Python 3.10～3.12。不能仅根据“Zero3W”这个称呼认定具备兼容 NPU。原代码适配 VIPLite 的模型输出及运行库，迁移到其他 SoC 需要其对应驱动与模型转换，不能只复制 `.nb`。

```bash
cat /proc/device-tree/model; echo
uname -a
python3 --version
ls -l /dev/video* /dev/serial/by-id/ /dev/vipcore
ls -l /usr/include/vip_lite.h /lib/libVIPhal.so /lib/libNBGlinker.so
ls -l /opt/yolov5/model/yolov5.nb
```

## 独立环境安装

```bash
cd ~/FaceLock_Gimbal_Face
bash tools/setup_orangepi.sh
```

安装脚本使用本仓库 `app/.venv`，不引用旧工程的 `.venv` 或 `.pth`。仅安装一个 OpenCV 发行包，避免 `opencv-python` 和 `opencv-contrib-python/headless` 混装。脚本会通过 sudo 安装系统依赖并添加设备组，组权限在注销并重新登录后生效。

NPU 有设备与头文件时，脚本在 `app/native` 现场编译 `libfacelock_vip.so`；否则明确提示缺少 SDK。桥接代码仍需与官方运行库、实际架构匹配，`pip install` 不能补齐内核驱动。NPU 模型及 SDK 的安装应使用实际板卡官方镜像/教程，不盲装别的 SoC 驱动。

权重固定至 OpenCV Zoo 提交 `48b10fa505aeb51fbd127fc60a5c660040e823b7`。权重不是本项目自己训练的。许可证在 `app/models/*LICENSE.txt`，来源在 `THIRD_PARTY_NOTICES.md`。

联网下载：

```bash
app/.venv/bin/python tools/models.py
```

网络不通时，将 E 盘新文件夹内 `offline_models_DO_NOT_UPLOAD` 一并复制到板子某处，然后执行：

```bash
app/.venv/bin/python tools/models.py --offline /你的离线模型目录
app/.venv/bin/python tools/models.py --verify
```

工具按哈希验证后才替换权重；Git LFS 指针或错误下载页不能通过。新副本中的 ONNX 可以用于本机测试，但不进入干净上传包。NPU `.nb` 由实际板端 SDK 提供，不能用 ONNX 文件直接冒充。

## 音频

```bash
aplay -l
espeak-ng --voices=cmn
printf '张三，欢迎光临。\n' | espeak-ng -v cmn -s 155 --stdin
```

使用离线合成，不需要云端 API、账号或密钥。音质为 espeak-ng 合成音；系统有声卡不代表已插扬声器，VNC 通常也不等于已将板端音频传到电脑。根据实际硬件选择 USB 声卡/有源音箱或可用音频接口，并设置系统默认输出、取消静音。音频命令成功但无声音时，先检查输出设备。
