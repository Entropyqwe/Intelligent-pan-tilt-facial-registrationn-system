# 启动、迁移与排错

## 重启后的标准流程

1. 给算力板和主控正常供电，接摄像头和通信接口。台架阶段电机 VM 断开。
2. 进入 VNC/本机桌面，点击“人脸欢迎与云台控制中心”；或进入仓库执行 `bash run.sh`。
3. 首次先运行“仅相机”，再运行“仅超声波遥测监听”，关闭前一个程序再打开下一个。
4. 未登记姓名时点“登记人脸姓名”；登记完关闭窗口，再运行人脸预览。
5. 视觉与姓名确认后，点“完整视觉＋人脸姓名＋语音＋云台＋测距”。
6. `Q` 或 Esc 退出视觉；`A` 切换自动/手动，`U` 解除，点击人体框/数字键可选择目标。

默认自动曝光；固定曝光只在调试工具完成可用画质验证并保存后，从“已保存固定曝光＋人脸预览”使用。不要把暗、噪声大或过曝画面保存为正式配置。

## 常用命令

下列命令均在仓库根目录执行：

```bash
bash run.sh --mode preview
bash run.sh --mode full
bash run.sh --mode full --port /dev/ttyUSB0
bash run.sh --mode body-only
bash run.sh --mode camera
bash run.sh --mode distance
bash run.sh --mode exposure
bash run.sh --mode fixed-preview
bash run.sh --mode enroll --name '张三'
bash run.sh --mode list
bash run.sh --mode speech-test --name '张三'
```

测距监听只收串口，不发控制，默认监听 10 秒。单轴验证使用 `--mode pan`、`tilt`、`front`，默认 ±50μs；须保持 VM 断开。相机预览显示采集 FPS；完整 UI 显示实际处理 FPS，两者不同。

停止程序优先在视觉窗口按 Q，或控制中心“停止当前视觉／验证程序”。入口使用同一硬件会话锁，避免同时启动两个设备消费者；旧工程如果另有进程占用设备，会拒绝新启动。

## 获取日志与性能记录

每次统一入口记录绝对工程路径、模式、命令和错误到 `app/logs/session_*.log`，视觉同时产生控制/遥测 CSV。不要把这些本机数据上传仓库。

```bash
ls -lt app/logs/
tail -n 100 app/logs/session_*.log
# 60秒仅预览测速：不打开串口，也不会驱动舵机。
bash run.sh --mode preview --max-seconds 60 --metrics-json logs/face_metrics.json
```

指标文件路径相对 `app/`，上例实际位于 `app/logs/face_metrics.json`。默认不写真人截图/录像。`face.completed` 为识别批次数，`face.last_ms` 为最近一次人脸推理耗时。

## 按现象排错

| 现象 | 先检查 | 处理 |
|---|---|---|
| 窗口未开/闪退 | 终端末尾错误与 `session_*.log` | 缺模型先恢复；缺NPU先核对驱动/模型；缺中文字体安装 `fonts-noto-cjk` |
| 显示旧界面 | 日志中的“项目”路径 | 只使用本副本 `run.sh` 和新桌面图标；不要调用旧 main.py |
| 摄像头打不开 | `ls /dev/video*`、`fuser /dev/video0` | 接数据口，关闭占用进程，检查集线器与供电 |
| 画面过暗/帧率下降 | 自动曝光、照明、真实采集FPS | 默认自动曝光，先补光再考虑固定曝光；不以变黑换数字帧率 |
| 人体01换人仍相同 | 单人槽位语义 | 01只是单人槽位；姓名必须重新人脸确认 |
| 姓名一直“未登记” | 名单、脸大小/清晰度、朝向 | 登记或补充本人样本；正面脸至少约75像素便于登记 |
| 姓名频繁“确认中” | 检测连续性、CPU负载 | 固定机位、补光，查看人脸耗时/错误；不降低身份阈值掩盖误认 |
| 人脸停用 | `face.error`、模型哈希 | 恢复对应ONNX并重新启动；普通模式人体继续，严格人脸模式停止有效跟随 |
| 有姓名没声音 | `aplay -l`、静音、espeak命令 | 先运行语音测试，选择正确默认声卡/音箱；VNC画面不保证转发音频 |
| 没有距离 | 是否选完整模式、TTL双向/GND、D1 | 仅预览不打开串口；先独立监听是否收到 `#D1`，再查ECHO |
| 舵机无动作 | G2/A1、三路信号、电源、公共GND | 分别单轴验证；收到PWM回传不能替代观察轴实际转动 |
| 电机不转 | UI“待标定/电机禁止”、VM、D1/M1 | 本副本默认禁止行进，须完成几何标定与整车验收后由电控同学启用 |

## 迁移到另一块板

复制干净仓库和需要的离线模型，在新板运行安装脚本并本机编译 NPU 桥。重新确认 SoC/SDK、串口设备、摄像头方向/视场、三路舵机方向/限位、超声波接线和供电。姓名库属于本机个人数据，若需迁移应单独私下复制，不放公开仓库。

固件路径是 `firmware/Objects/FaceLock_GIMBAL.hex`，Keil 工程是 `firmware/Project_VEHICLE.uvprojx`。使用 ST-Link/SWD；不是 TTL 烧录版。迁移新主控前必须核对针脚和板型，不能把 IOC 的可视化配置重新生成覆盖标准外设库工程。
