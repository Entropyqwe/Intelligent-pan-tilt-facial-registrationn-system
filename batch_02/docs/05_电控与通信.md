# 电控对接、引脚、协议与固件

## 本副本与原工程关系

源为E盘正式云台工程 `FaceLockCar_GIMBAL_20261104`。本次只在新目录加入人脸和语音，STM32源码、HEX和控制配置逐字节复制。没有烧录、没有远程启动实物。

固件内版本字符串为 `GIMBAL_20261105_R4_PAN_1000_2000`。它表示解析器允许范围，不是本次实测扩大了机械角度。运行配置仍只允许已验收的水平1100～1900、俯仰1300～1600、前轮1450～1550μs。

## 接口

| 引脚 | 模式/外设 | 当前作用 |
|---|---|---|
| PA0 | TIM2_CH1 PWM，50Hz | 底部水平云台 |
| PA1 | TIM2_CH2 PWM，50Hz | 前轮转向 |
| PA2 | TIM2_CH3 PWM，50Hz | 顶部俯仰云台 |
| PA9 | USART1 TX | 发主控遥测，接TTL RX |
| PA10 | USART1 RX | 收视觉指令，接TTL TX |
| PB6 | GPIO输出 | HC-SR04 TRIG |
| PB7 | TIM4_CH2输入捕获 | HC-SR04 ECHO，经3.3V兼容接口 |
| PB8/PB9 | GPIO软件总线 | OLED SCL/SDA，未被超声波复用 |
| PA6/PA7 | TIM3_CH1/CH2 PWM | TB6612 PWMA/PWMB |
| PB12/PB13 | GPIO输出 | AIN1/AIN2 |
| PB14/PB15 | GPIO输出 | BIN1/BIN2 |
| PB10 | GPIO输出 | TB6612 STBY |
| PA13/PA14 | SWD | ST-Link SWDIO/SWCLK |
| GND | 公共参考地 | 主控、TTL、舵机电源、驱动、超声波共地 |

接线图见 `assets/wiring/`。HC-SR04安装在随水平转、不随俯仰转的平台。ECHO按已有电平转换/分压方案接PB7，不把5V信号直接当3.3V信号；分压下端电阻接公共地，不是把ECHO直接短路到地。电机额定3.7V，不能把串联锂电池原电压或舵机5V电源不经核对直接接VM。

串口为115200、8N1、3.3V逻辑；TX/RX交叉、GND共地。TTL是USB串口桥，不负责算法，也不是ST-Link；以后改用算力板UART须另行确认设备、引脚、电平和系统配置，本副本没有自动改接。

## 指令保持

```text
@G1,seq,valid,pan_us,tilt_us,motion,age_ms*XX\n
@S1,seq,valid,target_id,bearing_mdeg,servo_us,age_ms,source*XX\n
```

`XX`为`@`后至`*`前ASCII字节逐字节异或校验的两位十六进制。通信线程20Hz发送G1后S1，同序号、有效位和观测年龄，配对间隔须小于100ms。原S1字段没有改动。

| 字段 | 含义 |
|---|---|
| seq | 递增序号，用于主控配对及跟踪 |
| valid | 是否有效新鲜人体控制；未知/丢失/严格身份不满足时为0 |
| pan_us/tilt_us | 水平/俯仰PWM微秒值 |
| motion | 算力板允许行进的门槛，当前未标定默认0 |
| target_id | 人体槽位/轨迹编号，**不传姓名** |
| bearing_mdeg | 人物相对车体方位，毫度 |
| servo_us | 前轮PWM，微秒 |
| age_ms | 自实际拍摄时刻起的年龄，不能以推理结束时刻替代 |
| source | 有效人体继续为2，无效为0；人脸不新增协议类型 |

人脸姓名和欢迎在算力板本地处理，不修改STM32解析器、不把人脸坐标代替人体坐标。

## 反馈与保护

主控回传 `#A1`（接收/应用确认）、`#D1`（距离及状态）、`#M1`（电机/前轮命令状态）、`#G2`（云台应用PWM/稳定状态等）。G2是软件输出值，**不是舵机编码器角度**；收到正确回传仍需观察真实机构。

- 距离≤300mm停车；≥350mm并满足恢复条件才重新允许启动。
- 距离250ms超时、视觉/串口500ms超时均禁止电机。
- 健康通信持续发送无效目标时，保持舵机当前位置3秒后回中；通信断链约500ms开始回中。
- 电机PWM目标约30%，约1秒缓升；没有轮速编码器，不能称为实测匀速闭环。
- 云台运动未稳定、测距未刷新、目标未对准、多目标或标定未完成，行进门槛不满足。

5. 本文、接线图、验收文档：先核对供电/共地/电平，再做串口、单轴、测距、联动。

首次烧录使用ST-Link/SWD，连接PA13、PA14、GND并按实际目标板方案供电；不要将多路电源随意并联。打开Keil不是烧录成功，需Build输出、Download/Verify结果及上电串口版本共同确认。

实车启用前由电控同学实测轴距、前轮PWM-轮角、相机内参/安装偏移、云台PWM-角度、测距误差与电机供电；再谨慎完善标定配置。保留原停车门槛，架空先测，然后有人负责急停的低速场地验收。
